## 데모 문구 허용 범위

말할 수 있는 내용:

- Spark가 자연어 요구와 상태 정보에서 검사 조건을 생성했다.
- SAM이 H1 영상의 625개 관측 중 624개에 위치를 반환했다.
- 원본 상태 값의 H1 조건 판정은 0.0~0.5초 PASS였고 저장 JSON 재평가가 일치했다.
- 저장된 실제 응답은 원본 해시를 대조한 뒤 새 호출 없이 이어서 볼 수 있다.
- 저장 결과 복구·조건 편집·재검사·내보내기 재불러오기는 Chrome에서 검증됐다.
- 기존 Mollet 기반과 해커톤에서 추가한 Meta 기능을 분리해 설명한다.

말하면 안 되는 내용:

- 624/625를 추적 정확도·IoU·성공률로 표현
- H1 조건 PASS를 전체 계단 성공이나 정책 품질로 확대
- 새 영상 기반 Spark 가설·재검토를 실제 실행 결과로 표현
- 교정 제안 코드를 새 정책 재학습이나 회복 성능 향상으로 표현
- 저장 응답 복구를 새 인증·새 모델 호출로 표현
- 사용자가 편집한 8초 조건이나 Go2 수동 조건을 Meta 모델이 생성한 새 결과로 표현
- 로컬 Meta 기능이 현재 공개 저장소에 반영됐다고 표현
- 3분을 공개 규정상 의무 상한으로 표현
- 기존 프로젝트 재사용이 명시적으로 허용됐다고 표현

1. 공식 폼의 필드명, 필수 여부, 선택지, 글자 수와 파일 업로드 조건을 기록한다. 공개 화면에서 확인되지 않은 문항 수는 추정하지 않는다.

5. 영상 URL이 로그아웃 상태에서 재생되는지 확인한다.
