# Mollet

Mollet은 로봇에게 원하는 행동을 검사 가능한 조건으로 바꾸고, 영상 위치와 상태 기록에서 조건을 만족한 구간을 찾는 로보틱스 작업 공간이다.

## 문제

보상 그래프는 정책의 전체 경향을 보여주지만 자세 조건이 충족되거나 무너진 시점을 설명하지 못한다. 실험 영상은 그 순간을 보여줘도 수치 조건을 반복해서 검사하기 어렵다. 로보틱스 개발자는 두 자료를 오가며 판단 근거를 다시 맞춰야 한다.

## 해결 방식

Muse Spark 1.3은 자연어 행동 요구와 상태 정보를 제한된 JSON 조건으로 작성한다. SAM 3.1은 영상에서 로봇 위치를 반환한다. Mollet의 판정기는 영상 시각과 맞춘 원본 상태 값에 조건을 적용해 PASS·FAIL·UNKNOWN과 근거 구간을 계산한다. 결과에는 조건, 영상 해시, 관측값과 검토 기록이 함께 남는다.

## 실제 Meta 실행 근거

- Muse Spark 1.3 호출 1회: `up_axis_z >= 0.8`, 시작 시각 0초, 충족 시작 마감 8초, 유지 시간 0.5초 조건 생성
- SAM 3.1 호출 1회: 625개 관측 중 624개에 로봇 위치 반환
- 로컬 판정: H1 기록의 0.0~0.5초 구간 PASS
- 재현성: 내보낸 JSON을 다시 평가해 같은 결과 확인, 원본 상태 값 불변

624/625는 위치 결과가 반환된 범위다. 정답 박스와 비교한 정확도나 IoU 수치가 아니다.

## 실브라우저 복구 검증

Chrome 156.0.8078.80에서 저장된 실제 Spark·SAM 응답을 키 없이 불러오고 H1 영상을 재생했다. 625개 상태와 624개 위치가 다시 연결됐고 SAM 위치 오버레이가 화면에 표시됐다. 원래 Spark 조건은 0.0~0.5초 PASS였으며, 사용자가 유지 시간을 8초로 바꾼 조건은 0.0~8.0초 PASS였다. 더 엄격한 조건과 Go2 기록의 12.48초 수동 조건은 FAIL이었다. 편집 결과를 내보내고 다시 불러왔을 때 값은 유지되고 승인 상태는 초기화됐다. 검증 전후 모델 호출 수는 2회로 같았고 예약 예산도 바뀌지 않았다.

## 최종 로컬 데모

영어 자막판과 한국어판을 각각 180초로 렌더했고 두 파일 모두 전체 디코드를 통과했다. 제출용 기본 파일은 영어 자막판 `submission/meta-recovery-demo-20261105-v2/mollet-meta-recovery-demo-180s-en-captioned.mp4`다. 1280×720 본문 아래에 120픽셀 자막 영역을 둔 1280×840 영상이며 표본 프레임에서 본문과 자막이 겹치지 않았다. 한국어판은 1280×720이다. 12개 장면 모두 한국어 SAPI 음성이 들어갔다.

## 이번 해커톤의 기여

기존 Mollet의 RL 실패 진단·회복 평가 기반과 계단 기록 위에 행동 조건 저작·검토 흐름을 추가했다. Meta 모델은 조건과 영상 위치를 제안하고, 성공 여부는 고정된 판정기가 원본 수치로 계산한다. 모델 응답을 그대로 성공 판정으로 쓰지 않으며 관측이 부족하면 UNKNOWN을 유지한다.

영상 기반 가설·재검토와 교정 제안 경로는 코드에 연결돼 있다. 다만 이 경로의 새 모델 추론, 정책 재학습, GPU 실행과 성능 향상 측정은 이번 실측 근거에 포함되지 않는다.

## 구성과 공개 상태

Python 로컬 서버, JavaScript 작업 화면, Meta Responses API, 제한된 JSON 스키마와 결정론적 시간 판정기를 사용한다. 기반 저장소는 Apache-2.0으로 공개돼 있다. 로컬 소스·브라우저·영상 검증은 끝났으며 Meta 기능의 원격 공개와 영상 공개 URL은 제출 전에 확인해야 한다.
