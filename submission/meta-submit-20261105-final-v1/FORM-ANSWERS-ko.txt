프로젝트명
Mollet

한 줄 소개
로봇의 행동 요구를 검사 가능한 조건으로 바꾸고, 영상 위치와 상태 기록에서 조건을 만족한 구간을 근거와 함께 확인하는 로보틱스 작업 공간입니다.

문제와 사용자
로보틱스 개발자는 보상 그래프와 실험 영상을 오가며 로봇이 의도한 행동을 했는지 확인합니다. 보상 점수는 자세 조건이 언제 충족되고 무너졌는지 알려주지 않으며, 영상만으로는 수치 조건을 반복 검사하기 어렵습니다. Mollet은 원하는 행동을 조건으로 작성하고 원본 영상과 시각이 맞춰진 상태 기록에서 같은 판정을 재현하게 합니다.

동작 방식
Muse Spark 1.3이 자연어 행동 요구와 상태 정보를 제한된 JSON 조건으로 변환합니다. SAM 3.1은 같은 영상에서 로봇의 위치를 반환합니다. 로컬 판정기는 프레임 시각에 연결된 원본 상태 값으로 시작 마감과 유지 시간을 계산합니다. 조건, 영상 해시, 관측값, 검토 기록과 결과는 하나의 JSON 근거 묶음으로 저장됩니다.

Meta 도구 활용
Meta Model API에서 Muse Spark 1.3과 SAM 3.1을 각각 한 번 호출했습니다. Spark는 H1 로봇의 수직축 정렬이 0.8 이상인 상태를 8초 안에 시작하고 0.5초 동안 유지하는 조건을 만들었습니다. SAM 응답은 625개 관측 중 624개에 로봇 위치를 연결했습니다. 이 값은 위치 결과가 반환된 범위이며 추적 정확도가 아닙니다.

확인한 결과
H1 조건은 0.0초부터 0.5초까지 PASS였습니다. 저장한 JSON을 다시 읽어 계산했을 때도 같은 결과가 나왔고, 원본 상태 값은 바뀌지 않았습니다.

브라우저 검증
Chrome에서 저장된 실제 Spark·SAM 응답을 키 없이 복구하고 H1 영상을 재생했습니다. 625개 상태와 624개 위치가 다시 연결됐고 SAM 위치 오버레이도 화면에 표시됐습니다. 사용자가 유지 시간을 8초로 바꾼 조건은 0.0~8.0초 PASS였으며, 더 엄격한 조건은 FAIL이었습니다. Go2 기록의 12.48초 수동 조건도 FAIL로 판정됐습니다. 편집한 JSON을 다시 불러오면 값은 유지되고 승인 상태는 초기화됐습니다. 이 과정에서 모델 호출 수는 2회로 유지됐고 예약 예산도 바뀌지 않았습니다.

이번 해커톤에서 만든 부분
기존 Mollet의 RL 진단 기반 위에 Meta 행동 조건 저작·검토 기능을 추가했습니다. 이번 기여는 Spark 조건 생성, SAM 영상 위치 결합, 시간 조건 판정, 조건 편집과 근거 내보내기입니다. 영상 기반 가설·재검토와 교정 제안 경로도 코드에 연결했지만, 이 경로의 새 모델 추론·정책 재학습·성능 향상 측정은 제출 근거에 포함하지 않습니다.

차별점
모델 출력 자체를 성공 판정으로 쓰지 않습니다. Meta 모델은 사람이 읽을 수 있는 조건과 영상 위치를 만들고, 최종 PASS·FAIL·UNKNOWN은 원본 상태 값과 고정된 판정 규칙으로 계산합니다. 근거가 부족하면 통과로 채우지 않고 UNKNOWN으로 남깁니다.

기술 구성
Python 로컬 서버, JavaScript 작업 화면, Meta Responses API, 제한된 JSON 스키마와 결정론적 시간 판정기를 사용합니다. 저장된 실제 응답은 원본 영상·상태 해시와 과거 공급자 실행 영수증을 대조한 뒤 키나 새 모델 호출 없이 복구 재생할 수 있습니다. 복구 중 공급자 인증을 새로 수행하지 않으며 새 추론으로도 기록하지 않습니다.

기존 작업과 신규 기여
기존 자산은 RL 실패 진단·회복 평가 기반과 저장된 계단 영상·상태 기록입니다. 해커톤 신규 기여는 Meta 기반 행동 조건 저작, 영상 위치 결합, 시간 판정과 증거 내보내기입니다. 기존 정책 학습이나 회복 결과를 Meta 기능의 새 성과로 합산하지 않습니다.
