## 답변별 검수 요약

### 1. Project Description

로봇 영상이나 보상 곡선만으로는 목표 행동이 언제 성립했는지 같은 조건으로 반복 검사하기 어렵다는 문제에서 시작한다. Mollet은 자연어 요구를 제한된 JSON 조건으로 바꾸고, SAM의 프레임별 로봇 위치와 원본 동기화 텔레메트리를 결합해 PASS, FAIL, UNKNOWN과 충족 구간을 계산한다.

H1 계단 기록에서는 `up_axis_z >= 0.8`, 시작 기한 8초, 유지 시간 0.5초 조건이 0.0초부터 0.5초까지 PASS였다. 유지 시간을 8초로 바꾼 조건은 0.0초부터 8.0초까지 PASS였고, 수동으로 작성한 Go2 전체 길이 12.48초 조건은 FAIL이었다. 조건을 수정하면 이전 검토 상태가 초기화되고, JSON을 내보냈다가 다시 읽어도 값이 보존된다는 점을 설명했다.

기존 RL 진단 기반과 계단 기록은 선행 자산으로 구분했다. 해커톤 신규 범위는 Meta 조건 작성, SAM 위치 결합, 시간 조건 판정, 검토 초기화, 내보내기 왕복, 저장 응답 재현이다.

### 2. Meta products

Muse Spark 1.3은 자연어와 상태 JSON을 받아 제한된 조건을 제안했다. 이 검증 호출에서 Spark가 원본 영상을 분석했다고 쓰지 않았다. SAM 3.1은 원본 H1 영상에서 625개 표본 중 624개에 로봇 박스를 반환했다. 이 수치는 응답 범위이며 추적 정확도가 아니다.

판정은 모델 출력이 아니라 원본 텔레메트리와 고정된 시간 규칙으로 계산한다. 현재 3분 영상은 인증된 과거 호출 2건의 저장 응답을 영수증과 해시로 검증해 재현하고, 현재 Chrome 화면을 담았다. 이 과정에서는 새 모델 호출이 없었다. 관련 검증은 CPU 테스트 142개와 Chrome 검사 10개를 통과했다.

영상 근거 가설, Spark 재검토, 교정 제안 경로는 코드로 구현했지만, 새 호출이나 재학습 결과로 서술하지 않았다.

### 3. Why Meta

Spark는 사람이 말한 행동 의도를 수정 가능한 조건으로 정리하고, SAM은 같은 영상에서 로봇의 위치를 보여준다. 원본 텔레메트리는 실제 판정 근거로 남는다. 세 역할을 분리하면 모델 제안을 검토하면서도 물리 행동의 성립 여부를 모델의 말만으로 확정하지 않는다.

Meta 모델이 다른 모델보다 우월하거나 독점 기능을 제공한다고 주장하지 않았다. 현재 증거가 뒷받침하는 범위는 사람의 의도, 영상 위치, 반복 가능한 로봇 판정을 감사 가능한 흐름으로 연결했다는 점이다.

## 제출 전 사실 경계

- 모델은 판정 정답이나 승인 권한이 아니다.
- 보상 교정, 정책 재학습, 회복 성능 개선을 이번 결과로 주장하지 않는다.
- SAM의 `624/625`는 위치 응답 범위이며 정확도가 아니다.
- 일반화 정확도, 시간 절감, 구매 효과 수치를 넣지 않았다.
- 파트너 피드백 선택 항목은 근거가 없으므로 공백으로 둔다.
- 개인정보, API 키, 마케팅 동의, 개인 설문 답변은 이 문서에 포함하지 않았다.
