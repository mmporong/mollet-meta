프로젝트명
Mollet

한 줄 소개
로봇에게 원하는 행동을 검사 가능한 조건으로 바꾸고, 영상 속 로봇 위치와 상태 기록에서 조건을 만족한 구간을 찾습니다.

문제와 사용자
로보틱스 개발자는 실험 영상을 반복해서 보며 원하는 행동이 나왔는지 확인합니다. 보상 그래프만으로는 자세 조건이 언제 충족됐고 언제 무너졌는지 알기 어렵습니다. Mollet은 원하는 조건을 작성하고 원본 영상과 상태 기록에서 근거 구간을 확인하는 작업 공간입니다.

동작 방식
Muse Spark 1.3이 자연어 요청을 제한된 JSON 행동 조건으로 변환합니다. SAM 3.1은 같은 영상의 이족 로봇 위치를 찾습니다. 판정기는 프레임 시각에 연결된 상태 값에서 조건을 계산합니다. 조건, 영상 해시, 관측값, 검토 기록과 판정은 JSON 파일로 함께 저장됩니다.

Meta 도구 활용
실제 Meta Model API로 Muse Spark 1.3과 SAM 3.1을 호출했습니다. Spark는 H1의 수직축 정렬이 8초 이내에 0.8 이상이 되고 그 상태를 0.5초 유지하는 조건을 생성했습니다. SAM 응답은 영상의 관측 625프레임 중 624프레임에 로봇 위치를 연결했습니다. 이 개수는 위치 결과가 연결된 범위이며 추적 정확도 측정값은 아닙니다.

확인한 결과
생성된 H1 조건은 0.0~0.5초 구간에서 충족됐습니다. 저장한 JSON을 다시 읽어 계산해도 같은 판정이 나왔습니다. H1과 Go2 계단 기록을 제공하며 상태 원문이 있는 기록은 시간 조건을 검사하고 요약만 있는 기록은 요약 범위에서 보여줍니다.

이번 해커톤에서 추가한 부분
기존 로보틱스 프로젝트와 저장 계단 자료 위에 Meta 행동 조건 편집기를 추가했습니다. 이번 작업은 Spark 조건 생성, SAM 영상 위치, 시간 조건 판정, 검토와 근거 내보내기입니다. 기존 RL 학습·회복 진단은 배경 인프라이며 새 정책 학습이나 새 회복 성과로 설명하지 않습니다.

기술 구성
Python 로컬 서버와 JavaScript 편집 화면을 사용합니다. 두 Meta 모델은 Responses API로 연결하며, 비밀키는 서버 메모리에 보관합니다. 앱 요청 예산은 로컬 예약 원장으로 제한합니다. 상태 누락이나 관측 공백, 부족한 시각 근거는 판단 보류로 남깁니다.
