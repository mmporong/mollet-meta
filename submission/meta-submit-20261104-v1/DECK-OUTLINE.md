# Mollet 발표 흐름

1. 문제: 보상 점수와 영상만으로 원하는 행동의 충족 구간을 찾기 어렵다.
2. 사용자 흐름: H1 영상 선택, 자연어 요청, Spark 조건 생성, SAM 위치 표시, 상태 판정과 JSON 내보내기.
3. 실제 근거: 두 Meta 완료 응답, H1 0.0~0.5초 PASS, JSON 재평가 일치. 화면 촬영과 저장 응답 편집 시연을 구분한다.
4. 기여 범위: 기존 RL 자료 위에 추가한 Meta 행동 조건 저작·검토 기능. 기존 정책 학습·진단 성과와 분리한다.
5. 실행 방법과 확장: 공개 소스의 로컬 실행, 상태가 없는 기록의 판단 범위, 새 행동 조건과 다른 기록으로의 적용.
