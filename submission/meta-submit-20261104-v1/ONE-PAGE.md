# Mollet

로봇에게 원하는 행동을 자연어로 적고, 영상과 상태 기록에서 조건을 만족한 구간을 확인한다.

로보틱스 개발자는 보상 그래프와 실험 영상을 함께 살펴본다. Mollet은 "8초 이내에 자세가 안정되고 0.5초 유지돼야 한다"는 요청을 Muse Spark의 JSON 조건으로 바꾸고, SAM의 영상 위치와 원본 상태 값을 같은 시각에 연결한다. 판정기는 조건 충족 구간과 관측이 부족한 구간을 구분한다.

실제 Meta 호출에서 Spark는 H1 자세 조건을 생성했고, SAM의 로봇 위치는 625개 관측 중 624개에 연결됐다. 상태 판정은 0.0~0.5초 구간에서 PASS였다. 조건과 관측을 저장한 JSON은 재평가에서도 같은 결과를 냈다. 위치가 반환된 프레임 수를 추적 정확도라고 해석하지 않는다.

Meta 작업은 기존 Mollet 저장소의 행동 조건 편집기로 구현했다. 기존 RL 학습·회복 진단과 저장 계단 자료를 재사용하며 이번 기여는 조건 저작, 영상 위치 결합, 시간 판정과 근거 내보내기다. 기존 정책의 학습 성능이나 회복 개선을 이번 성과에 더하지 않는다.

구성: Python 로컬 서버, JavaScript 편집 화면, Muse Spark 1.3, SAM 3.1, JSON 조건 판정기. 코드 라이선스는 Apache-2.0이다.
