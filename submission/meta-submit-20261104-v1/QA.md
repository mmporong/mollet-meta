# 예상 질문

## Meta 모델이 맡는 일은 무엇인가?

Muse Spark는 자연어 요청을 제한된 조건 스키마로 작성한다. SAM은 영상의 로봇 위치를 반환한다. 시각과 상태 수치로 조건을 계산하는 일은 Python 판정기가 맡는다.

## 기존 프로젝트와 이번 작업은 어떻게 다른가?

기존 Mollet은 RL 학습 실패를 조사하고 회복을 평가한다. 이번 Meta 작업은 개발자가 새 행동 조건을 만들고 저장 기록에서 검사하는 편집기다. 기존 계단 영상을 재사용하고 새 Meta 호출과 조건 결과를 별도 실행 기록에 보존했다.

## SAM의 624/625는 정확도인가?

위치 결과가 연결된 관측 프레임 수다. 별도의 정답 박스와 대조한 정확도나 IoU는 아니다.

## 조건 생성 오류는 어떻게 다루나?

허용된 지표·연산·시각·단위의 JSON 스키마를 통과해야 가져올 수 있다. 조건을 바꾸거나 모델 응답을 적용하면 검토 상태를 초기화한다. 관측이 부족하면 UNKNOWN으로 남긴다.

## 조건 통과가 계단 주행 전체 성공을 뜻하나?

지정한 조건과 구간에 대한 결과다. 진행·높이·전도 등을 함께 다루는 기존 회복 판정과 구분한다.

## 비밀키와 과금은 어떻게 관리하나?

비밀키는 서버 메모리에 보관하고 내보내기 파일에 넣지 않는다. 확인한 크레딧과 앱 예산 안에서만 명시된 요청을 보내며 예약 원장이 중복 지출을 제한한다. 데모는 이미 받은 실제 응답을 재사용한다.
