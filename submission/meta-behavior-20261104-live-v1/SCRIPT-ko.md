# Mollet 3분 데모 대본

이 영상은 저장 원본과 계산 결과를 편집한 시연입니다.

## 00:00:00,000 - 00:00:15,000 · live-title

Mollet은 로봇 영상과 상태 기록을 행동 조건으로 묶습니다. 이번 시연은 저장된 Meta 응답 두 건과 H1 계단 원본으로 만든 3분 검증 영상입니다.

## 00:00:15,000 - 00:00:30,000 · live-evidence

Muse Spark 1.3과 SAM 3.1 응답은 모두 인증된 HTTPS 호출로 완료됐습니다. 영상 제작 중에는 새 모델 호출을 하지 않았습니다.

## 00:00:30,000 - 00:00:45,000 · live-spark

Spark가 만든 조건은 시작 시점 0초, 수직축 정렬 0.8 이상, 8초 안에 시작, 0.5초 유지입니다. 저장된 응답 해시와 사용량도 함께 남겼습니다.

## 00:00:45,000 - 00:01:00,000 · live-sam

SAM은 H1 영상 625프레임을 처리했고 624프레임에서 객체 상자를 반환했습니다. 상자는 저장 응답의 프레임 번호에 맞춰 원본 위에 표시합니다.

## 00:01:00,000 - 00:01:15,000 · h1-live

지금 보이는 파란 상자가 SAM 응답에서 가져온 프레임별 위치입니다. 위쪽에는 시간과 자세 값, 아래쪽에는 조건과 추적 수를 표시했습니다.

## 00:01:15,000 - 00:01:30,000 · live-verdict

검사는 0초부터 0.5초까지 조건이 이어진 것을 확인해 통과로 판정했습니다. 판정은 영상 추적과 상태 값을 섞지 않고 각각의 출처를 보존합니다.

## 00:01:30,000 - 00:01:45,000 · live-export

내보낸 JSON에는 조건, 625개 관측값, SAM 추적 상자, 검토된 판정과 승인 범위가 함께 들어 있습니다. 다시 읽은 결과도 원본과 같았습니다.

## 00:01:45,000 - 00:02:00,000 · contract

자세 값 전체 구간을 그리면 임계값 0.8과 실제 기록의 간격을 확인할 수 있습니다. 이번 통과 구간은 시작 직후 0.5초입니다.

## 00:02:00,000 - 00:02:15,000 · compare

Go2 기록은 보조 비교로만 씁니다. 프레임 상태가 있는 기록과 요약만 있는 기록을 구분하고, 없는 시계열은 만들지 않습니다.

## 00:02:15,000 - 00:02:30,000 · live-integrity

두 Meta 응답의 요청과 응답 해시, 원본 영상 해시를 기록했습니다. 렌더링 과정의 새 API 호출과 GPU 작업은 모두 0건입니다.

## 00:02:30,000 - 00:02:45,000 · live-flow

흐름은 자연어 조건 생성, 영상 객체 추적, 상태 기반 판정, 근거 내보내기 순서입니다. 각 단계는 같은 원본 영상 해시로 연결됩니다.

## 00:02:45,000 - 00:03:00,000 · live-end

이 영상은 저장된 Meta 응답과 로봇 원본을 편집한 시연입니다. 브라우저 캡처나 새 학습 결과가 아니며, 재현에 필요한 해시와 판정 구간을 남겼습니다.
