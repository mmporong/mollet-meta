실제 응답을 결합한 결과는 로컬 에이전트 의미 검토 후 PASS(0~0.5초)였고, `mollet-behavior-contract.json`을 저장하고 다시 읽어 같은 판정을 확인했다. 검토자는 `co_meta_agent_semantic_review`이며 브라우저 사용자 검토나 실험 실행 권한으로 기록하지 않았다. 이 검증은 API·로컬 판정 경로이며 화면 클릭·재생·브라우저 다운로드 검증은 남아 있다.

## 원본 적용 검증 결과

원본에서 관련 80개 검사가 통과했다. `http://127.0.0.1:7705`는 원본의 `src`를 import하는 서버로 전환했다. 6개 영상의 HTTP 범위 응답이 원본 바이트와 일치하고, H1 상·하행과 Go2 저속 상·하행 4개 상태 기록의 초안 판정·JSON 저장·재판정이 일치했다. H1 상행은 원본 CLI에서도 같은 판정을 반환했다. 프레임별 상태가 없는 Go2 고속 2개는 판정을 만들지 않았다.

원본 적용 당시 검증의 내보내기는 화면의 JSON 구조를 HTTP 검사 스크립트로 직렬화한 결과다. 브라우저 다운로드·재생·클릭을 검증한 결과로 세지 않는다. 해당 과거 실행의 실제 Meta 호출은 0회였으며 이후 실제 호출 결과는 위 절과 새 실행 폴더로 구분한다.

7705 서버는 사용자가 키를 설정하고 MVP를 확인할 수 있도록 유지한다. 프로세스·로그·종료 명령은 저장소 밖 `hackathon-specialist/tmp/meta-authoring-preview-20261103.json`에 갱신한다. 원본의 다른 세션 변경과 `main` 포인터는 보존했다.

## 실행 범위

- 허용: 기존 키의 비노출 조회, 로컬 작성·검증·커밋, 원본의 Meta 추가 경로 반영, 확인된 지원 크레딧과 앱 예약 예산 안의 명시적 모델 요청.
- 키: Windows 환경변수, 문서에서 지정한 기존 Windows/WSL 설정 파일, 실행 중인 로컬 앱의 키 설정 여부를 확인한다. 키 원문을 대화·저장소·검증 보고서에 기록하지 않는다.
- 계정: 새 키 발급·카드 등록·계약 수락이 필요하면 해당 작업과 권한 요구를 사용자에게 구체적으로 알린다. 기존 키/계정 확인에 필요한 입력을 기다리는 동안 P4를 계속한다.
- 금지 유지: GPU·실물 로봇 실행·원격 push·대회 신청·제출. 개인 결제나 확인되지 않은 잔액으로 모델을 호출하지 않는다.

## 원본 적용 방법

소스는 `rl-triage-meta`, 대상은 `rl-triage-agent`다. 공통 기준 이후 Meta가 추가한 파일만 개별 경로로 복사하고 기존 파일이 있으면 SHA가 같을 때만 재사용한다. 데이터셋은 원본에 이미 있어 덮어쓰지 않는다.

공용 README·`.gitattributes`·트러블슈팅 문서는 전체 교체하지 않고 Meta 안내/규칙/절만 추가한다. 원본의 기존 tracked/untracked 변경은 되돌리거나 스테이징하지 않는다. 원본 적용 후 패키지 import 경로·파일 SHA·관련 검사·서버 작업 위치를 기록한다.

## 실제 요청의 실패 처리

- 첫 사례는 이미 본 개발 자료이므로 새 정확도·일반화·회복 효과로 보고하지 않는다.
- Spark는 완료된 구조화 JSON과 조건 스키마를 모두 통과해야 적용한다.
- SAM은 `response.completed`와 실제 원문을 보존한다. 빈 탐지는 완료된 빈 결과로 기록하며 객체 추적 성공으로 세지 않는다. 오류·미완료·잘못된 크기·영상 결합은 거부한다.
- 네트워크 실패·예산 소진 시 자동 재시도나 예약 환급을 하지 않는다. 기존 원문과 실패 기록을 남기고 재실행 조건을 명시한다.
- 실제 응답 또는 브라우저 조작이 없으면 그 단계는 차단/미검증으로 남긴다. 완료된 P4를 전체 기능 완료로 확대하지 않는다.

현재 상태는 이 문서와 기존 요구사항 문서에서 이어간다. 실행별 근거는 새 `evals/results/meta_original_integration_20261104_v1/` 폴더에 기록하고 덮어쓰지 않는다. 실제 모델 기록은 키를 포함하지 않는 기존 사용자 로컬 run 폴더를 사용한다. 결과 보고에는 P1~P4 상태와 미해결 계정·브라우저 조건, 원본 파일 반영과 `main` 이력 반영의 차이를 표시한다.

## 실제 응답을 반영한 제출 준비

추가 모델 호출 없이 `submission/meta-behavior-20261104-live-v1/`에 180초 영상을 생성했다. 실제 Spark 조건·완료 응답 SHA·사용량과 H1 위의 프레임별 SAM bbox를 사용한다. 저장 응답과 원본을 편집한 시연이며 브라우저 촬영으로 표시하지 않는다. H.264/yuv420p·AAC, 전체 디코드 성공, 한국어 내레이션 12개 구간과 표본 프레임 11개를 확인했다. 영상·대본·자막·원본/응답 SHA는 해당 manifest에서 연결한다.

`submission/meta-submit-20261104-v1/`에는 한·영 답변 모음, 원페이지, 발표 흐름, 예상 질문과 제출 전 확인표를 작성했다. 실제 실행 수치와 재사용 범위를 대조했다. 공식 제출 주소는 주최 메일에서 확인한 `https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit`이다. 로그인된 문항·최신 기존 자산 재사용 규정, 외부에서 읽히는 영상 URL, Meta 코드의 원격 공개, 최종 제출은 남아 있어 ready_to_submit은 false로 유지한다.
